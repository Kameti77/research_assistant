# AI Research Assistant

A simple AI-powered research assistant built with Python, LangChain, and Gemini.

It can:

* 🔎 Search the web for information
* 📚 Search Wikipedia
* 💾 Save research results to a text file
* 📋 Return research in a structured format

### Example

```text
What can I help you research?
Research the history of artificial intelligence.
```

The assistant researches the topic using the available tools and returns a structured summary with sources and the tools used.
